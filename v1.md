## 1. Project Overview

**SciAnomalyDupliNet** is a novel, lightweight deep learning architecture purpose-built to detect **copy-move forgery in scientific and biomedical images** — cell microscopy panels, gel blots, fluorescence images, and similar scientific figures.

### Why a new architecture?
Scientific images have a property that generic forgery detectors ignore: **high structural periodicity**. Cell lattices, gel bands, and tissue patterns repeat with regularity. A copy-move operation **breaks this natural periodicity** in a measurable, physics-grounded way. SciAnomalyDupliNet exploits this signal directly.

### Key innovations
| Innovation | Description |
|---|---|
| **Fourier Phase Correlation Map** | Classical FFT-based self-correlation to detect duplicated offsets |
| **Repetition Anomaly Score** | Sliding-window local autocorrelation deviation from global image periodicity |
| **RepAnom Cross-Attention** | Novel block that forces spatial features to attend to frequency tokens weighted by periodicity anomaly |
| **Anomaly-Guided Decoder** | Skip connections gated by the anomaly score — suppresses false positives in naturally periodic authentic regions |
| **Periodicity Consistency Loss** | Physics-grounded self-supervision: predicted forgery pixels should align with high anomaly score regions |

## 3. Preprocessing Pipeline

### 3.1 Spectral Prior Computation (`spectral_priors.py`)
Runs **before** the neural network, on CPU, during data loading. Produces a 2-channel prior:

#### Channel 0 — Phase Correlation Map
```
1. Apply Hann window to grayscale image
2. Compute FFT → F
3. Normalized cross-power spectrum: G = F * conj(F) / |F * conj(F)|
4. Inverse FFT → phase correlation surface (fftshift to centre DC)
5. Zero out DC peak (radius = image_size // 64)
6. Normalise to [0, 1]
```
Peaks in this map reveal the translation offset of copy-moved regions.

#### Channel 1 — Repetition Anomaly Score
```
1. Compute global autocorrelation template from full image FFT
2. Sliding window (32×32, stride 16) over downscaled image:
   - Per-patch FFT → local autocorrelation
   - L1 deviation from global template → local anomaly score
3. Accumulate (average overlapping patches)
4. Gaussian smooth (σ = window/4)
5. Normalise to [0, 1]
```
High values = local periodicity deviates from global expectation = likely forged.

**Working resolution:** Both priors are computed at 256×256 then upscaled to 512×512 (fast, no meaningful information loss).

## 4. Architecture

```
Input: RGB (3ch) + Spectral Prior (2ch)
         ↓ concatenate → 5 channels
┌─────────────────────────────────────────────────────────────┐
│ ENCODER: MobileViT-XS  (pretrained ImageNet, stem patched)  │
│                                                             │
│  Stem conv: 5→16ch  (extra 2ch init with N(0, 0.01))       │
│  F1: (B, 32, 128, 128)                                      │
│  F2: (B, 48,  64,  64)                                      │
│  F3: (B, 64,  32,  32)                                      │
│  F4: (B, 80,  16,  16)   ← deepest features                │
└─────────────────────────────────────────────────────────────┘
         ↓ F4
┌─────────────────────────────────────────────────────────────┐
│ FREQUENCY BRANCH                                            │
│  rfft2(F4) → log magnitude spectrum                         │
│  adaptive_avg_pool2d → (B, 80, 8, 8)                       │
│  flatten → (B, 64, 80)                                      │
│  Linear(80→128) → ReLU → Linear(128→128)                   │
│  Output: freq_tokens (B, 64, 128)                           │
└─────────────────────────────────────────────────────────────┘
         ↓ F4 + freq_tokens
┌─────────────────────────────────────────────────────────────┐
│ RepAnom CROSS-ATTENTION  ★ NOVEL ★                          │
│  Q = Linear(80→80)(F4 flattened) — spatial patches         │
│  K = Linear(128→80)(freq_tokens)                            │
│  V = Linear(128→80)(freq_tokens)                            │
│  Scaled dot-product (4 heads)                               │
│  Residual + LayerNorm                                       │
│  reshape → F4_enriched (B, 80, 16, 16)                     │
└─────────────────────────────────────────────────────────────┘
         ↓ F4_enriched
┌─────────────────────────────────────────────────────────────┐
│ ANOMALY-GUIDED DECODER (U-Net style)  ★ NOVEL ★            │
│                                                             │
│ Each decoder block:                                         │
│   ConvTranspose2d (upsample ×2)                             │
│   anomaly_gate = sigmoid(Conv1x1(anomaly_map_at_scale))    │
│   skip = skip * (1 + anomaly_gate)  ← boost forged regions │
│   cat(upsampled, gated_skip, anomaly) → ConvBnRelu         │
│                                                             │
│  Dec4: (80→256)   F3 skip (B,64,32,32)                     │
│  Dec3: (256→128)  F2 skip (B,48,64,64)                     │
│  Dec2: (128→64)   F1 skip (B,32,128,128)                   │
│  Final: ConvTranspose2d → ConvBnRelu → 32ch                │
│  Head: Conv1×1 → 1ch logits                                 │
└─────────────────────────────────────────────────────────────┘
         ↓
  Output: (B, 1, 512, 512) — logits (apply sigmoid for mask)

Total parameters: ~8–9 M
VRAM at batch=6, img=512: ~3.5–3.8 GB (with AMP + grad checkpointing)
```

### MobileViT-XS Backbone
- Family: Mobile Vision Transformer (Apple, 2021)
- Combines MobileNet depthwise convolutions with lightweight local transformers
- Pretrained on ImageNet-1k (9.34 MB weights via HuggingFace / timm)
- Stem is **patched** from 3→5 input channels: pretrained RGB weights are preserved, extra 2 channels initialised with `N(0, 0.01)`

## 5. Loss Function

```
L_total = 1.0 × BCE
        + 1.0 × Dice
        + 0.4 × Focal (γ=2, α=0.25)
        + 0.1 × PeriodicityConsistencyLoss
```

### Periodicity Consistency Loss (novel)
```
For pixels where ground truth mask = 1 (forged):
    L_pos = MSE(anomaly_map[gt_pos], 1.0)   × 0.7
For pixels where ground truth mask = 0 (authentic):
    L_neg = MSE(anomaly_map[gt_neg], 0.0)   × 0.3

PeriodicityConsistencyLoss = L_pos + L_neg
```
This term acts as **physics-grounded self-supervision**: it teaches the model that its forgery predictions must be consistent with the Fourier repetition anomaly signal. This drastically reduces false positives on naturally periodic (but authentic) regions.

## 6. Training Strategy

| Setting | Value |
|---|---|
| Optimizer | AdamW (lr=3e-4, wd=1e-4) |
| LR schedule | Cosine annealing with 3-epoch linear warm-up |
| Precision | float16 (torch.amp) + GradScaler |
| Gradient clip | max_norm = 1.0 |
| Batch size | 6 (configurable) |
| Image size | 512×512 |
| Epochs | 30 (configurable) |
| Val metric | Dice coefficient |
| Checkpointing | Every epoch (`last_model.pth`) + best val Dice (`best_model.pth`) |
| Auto-resume | Yes — just re-run `python train.py` |

## 7. Configuration

All hyperparameters live in **`config.py`** — the only file you need to edit:

```python
EPOCHS          = 30        # total epochs
BATCH_SIZE      = 6         # reduce to 2-4 if OOM
IMG_SIZE        = 512       # reduce to 384 to save VRAM
LEARNING_RATE   = 3e-4
WEIGHT_DECAY    = 1e-4
WARMUP_EPOCHS   = 3
GRAD_CLIP       = 1.0

LOSS_BCE_WEIGHT    = 1.0
LOSS_DICE_WEIGHT   = 1.0
LOSS_FOCAL_WEIGHT  = 0.4
LOSS_PERIOD_WEIGHT = 0.1    # Periodicity Consistency weight

OUTPUT_DIR      = "checkpoints"
AUTO_RESUME     = True      # auto-resume from last_model.pth
```

## 9. Commands

### Install dependencies
```bash
pip install -r requirements.txt
```

### Smoke test (verify no crash, check VRAM)
```bash
python train.py --debug
```
Expected: 1 epoch on 4 samples, prints loss breakdown + Peak VRAM (should be < 4 GB).

### Full training
```bash
python train.py
```
Reads all settings from `config.py`. Auto-resumes if `checkpoints/last_model.pth` exists.

### Force fresh training (ignore existing checkpoint)
```bash
python train.py --no-resume
```

### Resume from a specific checkpoint
```bash
python train.py --resume checkpoints/last_model.pth
```

### Override config on the fly (without editing config.py)
```bash
python train.py --epochs 50 --batch 4 --img-size 384 --lr 1e-4
```

### Run EDA / Dataset verification
```bash
python eda_dataset.py
```
Expected: Generates an `eda_samples.png` showing multiple images with their masks and spectral priors.

### Run inference on all test images
```bash
python predict.py --data IF-Data --checkpoint checkpoints/best_model.pth --output predictions
```

### Run inference on a single image
```bash
python predict.py --input "IF-Data/test_images/0.png" --checkpoint checkpoints/best_model.pth --output predictions
```

### Use fixed threshold instead of Otsu auto
```bash
python predict.py --threshold 0.5 --checkpoint checkpoints/best_model.pth --output predictions
```

## 10. Expected Metrics

| Metric | Target |
|---|---|
| **Val Dice** | > 0.70 by epoch 15, > 0.80 by epoch 30 |
| **Val loss** | Steadily decreasing; stable after epoch 20 |
| **Peak VRAM** | < 4 GB at batch=6, img=512 |

### Interpreting training output
```
[E5 0/390] loss=1.2341 | bce=0.4521 | dice=0.5123 | focal=0.3211 | period=0.1021
```
- `bce` should dominate early, then drop
- `dice` loss should decrease steadily (lower = better overlap)
- `period` loss converging toward 0 means model predictions align with physics signal
